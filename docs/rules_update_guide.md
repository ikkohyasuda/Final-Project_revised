# rules.csv 更新手順（初心者向け）

## 目的
`rules.csv` を編集して薬剤・症状のルールを更新し、アプリに反映させる手順です。

## 更新の流れ（最短手順）
1. `rules.csv` を編集する
2. 反映コマンドを実行する
3. 反映結果を確認する

## 1. rules.csv を編集する
場所: `rules.csv`

列の意味:
- `category`: 薬剤カテゴリ（例: 低血糖、抗コリン）
- `effect_name`: 代表的な注意点（例: 冷や汗・手のふるえ）
- `keywords`: 薬剤名（商品名/一般名を区別しない）。`|` 区切りで複数記載
- `symptoms`: 症状名。`|` 区切りで複数記載

記載例:
```
低血糖,冷や汗・手のふるえ,アマリール|グリメピリド,冷や汗|手のふるえ|強い空腹感|意識がぼんやりする
```

## 2. 反映コマンドを実行する
ターミナルで以下を実行します:
```
python backend/app/db/seed_db.py
```

## 3. 反映結果を確認する
アプリを起動し、照合を確認します。
```
python backend/app/app.py
```

ブラウザで `http://localhost:8000/check` を開き、`image_id` を入力して `matched` に反映されるか確認します。

## よくある質問
### Q. 追加したのに反映されません
- `rules.csv` に保存できているか確認してください
- `python backend/app/db/seed_db.py` を実行したか確認してください
- サーバーが起動中なら一度再起動してください

### Q. 同じ薬が複数カテゴリにある場合は？
- 最初に登録されたカテゴリだけが `drug_category` に保存されます
- 症状の紐付けはすべて作成されます
